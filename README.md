# dotfiles

Personal configurations for nvim, zsh, tmux, etc.

## TL;DR

### macOS

```
git clone git@github.com:b-ggs/dotfiles.git $HOME/.files
cd $HOME/.files
make brew-bundle
make macos-configure
```

### Debian and Ubuntu

```sh
git clone https://github.com/b-ggs/dotfiles.git "$HOME/.files"
cd "$HOME/.files"
make linux-install
make linux-configure
```
